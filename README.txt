# Ayush Portfolio (HTML + CSS)

## Run
1. Extract this folder.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. All image assets are in `assets/`.

## Customize
Search in `index.html` for `Ayushbeer Singh`, email, phone placeholders, project titles, descriptions, and social links.
The images are crops of the exact images visible in the screenshots you supplied. The screenshots do not include the original standalone image files, so these crops are limited to the resolution visible in the screenshots.
The contact form is front-end only; connect it to a backend or form service to receive messages.
